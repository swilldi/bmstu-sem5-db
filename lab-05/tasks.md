# Лабораторная 5 — что нужно сделать

Всё собрать в один `lab05.sql`, по пунктам. Запуск с хоста (иначе `\o` не сможет писать файлы):

```bash
PGPASSWORD=postgres psql -h localhost -p 5433 -U postgres -d study -f lab05.sql
```

## 1. Выгрузка в JSON

- [ ] Таблица `track` одним массивом → `track.json`
- [ ] Вложенный документ из связки таблиц (протокол гонки или пилот → контракты) → `race.json`

## 2. Загрузка JSON в таблицу

- [ ] `track.json` → `json_import` (документ как есть)
- [ ] `track_copy (LIKE track INCLUDING ALL)`, заполнить из документа
- [ ] `EXCEPT` в обе стороны = 0 строк

## 3. Атрибут jsonb

- [ ] `race_entry.pit_stops` + заполнение (взять из `pit_stops.sql`)

## 4. Работа с документом (на `pit_stops`)

- [ ] 4.1. Фрагмент: первый пит-стоп целиком (`pit_stops -> 0`)
- [ ] 4.2. Значение: длительность первого стопа числом
- [ ] 4.3. Существование: заезды со стопом на `wet` (`@>` или `@?`)
- [ ] 4.4. Изменение: поменять шину в стопе (`jsonb_set`) или добавить стоп в массив (`||`)
- [ ] 4.5. Разбиение: пит-стопы заезда в строки (`jsonb_array_elements` или `JSON_TABLE`)
